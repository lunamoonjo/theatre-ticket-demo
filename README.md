# Театральная афиша и продажа билетов — частичная реализация

Демонстрационный frontend для курсовой работы по проектированию информационной системы продажи театральных билетов.

## Что реализовано

- просмотр афиши спектаклей;
- поиск по спектаклям;
- фильтрация по жанру;
- просмотр расписания конкретного спектакля;
- выбор сеанса;
- схема зрительного зала;
- отображение свободных, выбранных и занятых мест;
- расчет стоимости в зависимости от категории места и выбранного сеанса;
- форма ввода ФИО, телефона и электронной почты;
- демонстрационное оформление билета;
- сохранение занятых мест в `localStorage` браузера.

## Запуск локально

Проект не требует backend и сторонних библиотек.

Самый простой вариант — открыть `index.html` в браузере.

Для работы через локальный сервер можно, например, использовать расширение **Live Server** в VS Code.

## Загрузка на GitHub

1. Создайте новый репозиторий на GitHub.
2. Скопируйте в него `index.html`, `styles.css`, `script.js` и `README.md`.
3. Закоммитьте изменения и отправьте их в репозиторий.
4. Для публикации демонстрации можно включить **GitHub Pages**.

## Важно для курсовой

Названия спектаклей, даты и цены в `script.js` являются демонстрационными значениями, поскольку исходный документ курсовой задает состав и структуру данных, но не содержит конкретного репертуара.

Интерфейс отражает описанные в курсовой функции: просмотр афиши и расписания, выбор места, расчет стоимости и оформление билета.
