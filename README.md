# Театральная афиша и продажа билетов — частичная реализация


## Что реализовано

- просмотр афиши спектаклей;
- поиск по спектаклям;
- фильтрация по жанру;
- просмотр расписания конкретного спектакля;
- выбор сеанса;
- схема зрительного зала;
- отображение свободных, выбранных и занятых мест;
- расчет стоимости в зависимости от категории места и выбранного сеанса;
- форма ввода ФИО, телефона и электронной почты;
- демонстрационное оформление билета;
- сохранение занятых мест в `localStorage` браузера.
